# Nova Miner

Crea una web de mineria en la nube. Con una nav bar con las siguientes secciones: Dashboard, earn power, faucet, lottery, games, faq y logout.  Diseño dark-blue, blockchain futurista, fondo web con nodos blockchain react al mouse. En el dashboard debe estar la mineria virtual-cloud, monedas que podrá minar: BTC, ETH, LTC, SHIB, DOGE, TRX, BNB, SOL, POL, ETC, BCH, XRP, ADA, ATOM. cada tarjeta debe tener un tamaño de 290x140, con el balance de la moneda y una barra slide para que el usuario pueda aumentar o disminuir el poder de minado de la moneda, si el usuario quiere minar varias a la vez debe repartirse el 100% de su moneda dividido segun el poder de minado que le da a cada moneda., mineria en vivo aumentando cada segundo (como lo hacen los milisegundos de un cronometro) El dashbaord debe mostrar el poder de minado del usuario, el cual ganará 100 h/s por registrarse de manera gratuita.
